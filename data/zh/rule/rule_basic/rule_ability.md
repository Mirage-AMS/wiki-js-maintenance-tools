# 1. 晋升区

在《传奇之路》中，每个玩家的角色面板内都有1个3行、共10个栏位的晋升区。

从低到高，晋升区可被分为低级行（3个栏位）、中级行（3个栏位）和高级行（4个栏位）。

晋升区代表当前可供使用的能力（技能·造物·法术等），随着解锁的能力增多，玩家将变得越发强大。

<br>

# 2. 常规解锁

在晋升区进行常规解锁时，需要满足以下的基本规则：

- 解锁能力时，必须优先使用**较低等级行**上的**空栏位**；
- 解锁能力时，必须**使用不低于待解锁能力等级**的行：
    - 低级能力可以解锁在任意位置；
    - 中级能力必须解锁在中级或高级行；
    - 高级能力必须解锁在高级行。
- 解锁能力时，必须**已解锁一个较低等级的能力**：
    - 中级能力解锁前，你必须已解锁一个低级能力；
    - 高级能力解锁前，你必须已解锁一个中级能力。

在此基础上，当玩家满足持有的情报卡牌的解锁条件时，可以支付对应的解锁代价，将手牌中的情报卡牌放置于符合规则的晋升区栏位上，视为进行（常规）解锁。

完成解锁的原情报卡牌，以其在晋升区明置为限，其卡牌类型视为其记述的能力类型（技能·造物·法术等）。

根据能力的类型，解锁还有额外规则。

<br>

## 2.1. 技能解锁

技能解锁时，需要玩家消耗特定数目的金币。

<br>

## 2.2. 造物解锁

造物解锁时，需要玩家持有特定的卡牌（植物、动物、生物、情报等）。

进行解锁时，玩家必须将这些卡牌堆叠在被解锁造物卡牌的下方，它们被视为被解锁造物的素材。

- 某些卡牌在作为素材时，获得额外效果，见：[作为素材获得额外效果的示例](/rule/rule_basic/rule_effect#h-33-素材的效果-鳄鱼为例)；
- 某些造物会与其素材发生交互，见：[与素材交互效果的示例](/rule/rule_basic/rule_effect#h-36-与素材交互的效果-一千零一夜为例)；
- 造物因为效果从场上被移除时，其下方堆叠的素材也被弃置。

<br>

## 2.3. 法术解锁

法术解锁时通常需要消耗元素，元素的基本规则见：[元素](/rule/rule_basic/rule_element "元素相关的规则")。

<br>

# 3. 直接解锁

当玩家的背包栏位中有造物卡牌（通常仅能从交易资源区通过购买获得）时，只要满足常规解锁的前提条件，即可直接将该造物从背包解锁到晋升区的空栏位，这样的解锁（无需支付解锁代价）称之为直接解锁。

<br>

# 4. 移除解锁

**玩家通常不能将晋升区中已解锁的卡牌直接移除。**

但存在一些情形，玩家可以通过效果移除晋升区栏位中已解锁的卡牌，进而导致晋升区栏位出现空缺。

此时，晋升区已解锁的卡牌遵循以下规则：

- 当玩家在任意等级晋升区栏位上产生空栏位时，直至空栏位被补全之前，在那些高于（不含）该等级的晋升区栏位上：
    - 玩家已被解锁的能力被**禁用**；
    - 玩家不能将新的能力解锁；
- 当能力被禁用时：
    - 玩家不再适用被禁用能力的永久类效果；
    - 玩家不能发动禁用能力的启动·快速类效果；
    - 那个能力处理中的效果仍正常处理；
    - 该能力仍被视为1个已解锁的能力。

以上变更的本质仍是遵循晋升区栏位解锁的基本规则（不允许存在空栏位，自下而上解锁），为该规则的例外补充。

当发生解锁卡牌被移除后，被移除的卡牌（及其素材）按照规则弃置。

<br>

# 5. 废除晋升区栏位

**目前仅有极少数的卡牌效果可以废除晋升区栏位。**

玩家适用或发动废除晋升区栏位的效果时，可以任意选择空置的或已有解锁卡牌的栏位。

废除晋升区栏位后，该栏位的卡牌（及其素材）按照规则弃置。

被废除的晋升区栏位既不视为空置，也不视为已有解锁卡牌，而是视为“不存在该栏位”。
- 在低级、中级晋升区栏位被废除后，因其“不存在”，因此不会空置出晋升区栏位（避免存在空的晋升区栏位导致高等级的晋升区栏位失效）；
- 晋升区栏位被废除后，无法被用于解锁任何卡牌，同时也无法被任何效果互动。

晋升区栏位废除、规则移除已解锁卡牌均不影响效果结算（同其他移除、弃置类效果结算流程）。
