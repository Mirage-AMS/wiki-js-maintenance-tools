# 1. 情报资源区

在《传奇之路》中，有1个供所有玩家获取信息的情报资源区，名为“秘密集会”。

从“秘密集会”中探听信息，补足自身薄弱的环节，是通往传奇的必经之路。

情报资源区由以下要素构成：

- 1个资源牌堆：资源牌堆是资源区的全部内容物，包含60张卡牌（启用卡牌扩展包 01后， 包含90张卡牌）；

- 1个弃牌堆：弃牌堆是所有被弃置的该资源区卡牌的最终去处，同时也是资源牌堆的补充来源。

<br>

# 2. 获取卡牌

游戏进行中，当玩家需要执行抽牌时，总是从情报区牌堆顶抽取对应数目的卡牌。

- 游戏开始前，玩家从情报区抽取卡牌作为初始手牌，并可进行1次调度；

- 每个回合的 ${tDrw} 和 ${tAct}，玩家均可根据规则从情报区抽取卡牌；

- 除此之外，玩家也可以发动能力和事件的效果从情报区抽取卡牌。

_特别地，当情报区牌堆中没有足够卡牌时，需将弃牌堆洗回资源牌堆中。_

玩家从情报资源区抽取的卡牌均以非公开手牌的形式存放。**手牌上限为6**。

- ${tEnd} ，若玩家手牌数目超出上限，玩家必须弃置手牌，直到手牌等于手牌上限。

<br>

# 3. 情报卡牌

情报资源区中大多数卡牌为情报卡牌，情报卡牌象征着玩家从多种渠道获得的信息，这些信息可以帮助玩家解锁能力，见：[能力与晋升](/rule/rule_basic/rule_ability)。

当玩家获得情报卡牌时，总是将其加入到手牌。

玩家不能直接从手牌发动情报卡牌上记述的效果。

玩家可以出售情报卡牌。

<br>

# 4. 事件卡牌

情报资源区包含一种类型为事件的卡牌，事件卡牌象征着一些发生在环境中的事件，一些事件为玩家提供额外的信息和资源，一些则会限制其他玩家的发挥。

事件卡牌不同于情报卡牌，如需发动或适用它的效果，不需要（也不能）将其解锁。

当玩家获得事件卡牌时，总是将其加入到手牌。

当玩家满足该事件卡牌的发动条件时，可以宣言发动事件并将其从手牌弃置（按规则送去对应的弃牌堆），那之后处理事件的效果。

玩家可以出售事件卡牌，其出售处理同情报卡牌。

<br>

# 5. 专属资源区和专属卡牌

启用角色扩展包后，游戏中新增了1个和角色关联的区域，称之为专属资源区。

专属资源区位于角色面板左上方，是1个用于存放角色专属卡牌的区域。

专属资源区由以下要素构成：

- 1个资源牌堆：公开的、包含该角色所有的专属情报和专属事件卡牌的牌堆，这个牌堆没有顺序，来源于该牌堆中的卡牌被弃置时，回到该牌堆中。

启用角色扩展包后，专属区遵循以下规则：

- 在游戏开始前，每名玩家选择自己要使用的角色，并将对应的专属情报和专属事件卡牌加入到专属区中；

- 在每个回合的 ${tDrw}，玩家可以不从情报区抽取卡牌，而是选专属区中的1张专属卡牌获得。

_特别地，玩家从专属区获得的卡牌均没有售出价格，因而无法被出售。_
